# 絶対に負けない三目並べ

スマホ最適化された2人プレイヤー向けの三目並べ（Tic-Tac-Toe）ゲームです。

## 特徴

- 📱 **スマホ完全最適化**: タッチ操作に最適化された快適な操作性
- 🎨 **美しいデザイン**: モダンでカラフルなUI
- ⚡ **スムーズなアニメーション**: 滑らかな動きと視覚効果
- 🏆 **スコア記録**: ローカルストレージでスコアを自動保存
- 📳 **振動フィードバック**: タッチ操作時の触覚フィードバック（対応デバイスのみ）
- 🔄 **レスポンシブ**: あらゆる画面サイズに対応

## 遊び方

1. `index.html` をブラウザで開く
2. プレイヤーX（赤）から始まります
3. 空いているマスをタップして自分のマークを置きます
4. 縦・横・斜めのいずれかで3つ揃えたプレイヤーの勝利です
5. 「もう一度」ボタンで新しいゲームを開始
6. 「スコアリセット」ボタンで累計スコアをリセット

## 技術スタック

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript (ES6+)
- LocalStorage API
- Vibration API

## スマホ最適化機能

- ビューポート設定でモバイルブラウザに最適化
- タッチイベントのパフォーマンス最適化
- ダブルタップズーム防止
- 画面の向き変更に対応
- 大きなタッチターゲット（アクセシビリティ向上）
- PWA対応準備済み

## ブラウザサポート

- iOS Safari 12+
- Android Chrome 70+
- その他モダンブラウザ

## ローカルで実行

```bash
# リポジトリをクローン
git clone <repository-url>

# ディレクトリに移動
cd Qi_game

# ブラウザで開く
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

または、任意のWebサーバーで公開してアクセス可能です。
